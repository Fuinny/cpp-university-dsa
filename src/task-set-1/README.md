# Task Set 1: Stack

### Task 1
Convert a non-negative integer to binary using a stack data structure.
Implement the stack as a fixed-size array.

Example:
```
Enter a number: 13
Binary: 1101
```

---

### Task 2
Using a stack for word processing, create a program that outputs the word you type in reverse order.

Example:
```
Enter a word: Hello
Reversed word: olleH
```

---

### Task 3
Modify the previous program to determine whether the entered word is a palindrome.
You may use multiple stacks or implement a queue and use it with the stack.

Example:
```
Enter a word: Level
Word is a palindrome.

Enter a word: SomethingElse
Word is not a palindrome.
```

---

### Task 4
Implement the previous task using C++ STL containers for the stack and/or queue.

Example:
```
Enter a word: Level
Word is a palindrome.

Enter a word: SomethingElse
Word is not a palindrome.
```
