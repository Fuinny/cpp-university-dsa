# Task Set 2: Linked List

### Task 1
A text file contains the grades of a group of students.
Create a dynamic linked list class to store these grades, read them from the file, and populate the list accordingly.
Additionally, calculate the average grade of all students stored in the list and display it on the screen.

Example:
```
Group Grades:
9 7 10 6 8 9 7 8 5 10 6 8 7 9 6 10 5 8 7 9

Group Average:
7.7
```

---

### Task 2
Extend the linked list by adding two more data fields to each node: student name and student surname.
Implement sorting functionality in the list class.
In the main program, allow the user to choose which attribute to use for sorting - by name, surname, or grade.
At the start of the program, read the list of students from the input file and display it.
Then, present the user with a menu that provides all available list management options.

Example:
```
1. Display the list
2. Insert element
3. Remove element
4. Sort list by name
5. Sort list by surname
6. Sort list by grade
7. Display average grade of the group
8. Exit

Enter your choice:
``
