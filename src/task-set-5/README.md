# Task Set 5: Graphs

### Task 1
Implement different search strategies in graphs such as depth-first search (DFS) and breadth-first search (BFS) algorithms.
These search algorithms can be implemented using stack (DFS) and queue (BFS) data structures, and/or recursively.

```
BFS: 5 3 8 9 7 4 1 2 6
```
