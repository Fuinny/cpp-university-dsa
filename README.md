# C++ DSA University Coursework Archive

This repository is an archive of C++ DSA university coursework.

## Repository Structure

The project is organized into task sets, each containing multiple individual tasks:

- [Task Set 1](src/task-set-1/): Stack
- [Task Set 2](src/task-set-2/): Linked List
- [Task Set 3](src/task-set-3/): Binary Tree
- [Task Set 4](src/task-set-4/): Hash Table
- [Task Set 5](src/task-set-5/): Graphs
- [Task Set 6](src/task-set-6/): Additional Tasks

## Building the Project

1.  **Configure the project**:
    Choose a preset (either `clang-debug` or `clang-release`):
    ```bash
    cmake --preset clang-debug
    ```

2.  **Build the project**:
    ```bash
    cmake --build --preset clang-debug
    ```
